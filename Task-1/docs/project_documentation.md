# Project Documentation 

## Purpose 
A relational database for a retail store to manage customers, products, suppliers, employees and sales, replacing a spreadsheet-based approach.

## Work completed
1. Designed several related tables and created them with 'schem.sql'.
2. Loaded sample data with 'sample_data.sql'.
3. Practiced DDL ('ddl.sql') and DML ('dml.sql').
4. Wrote retrieval queries and basic reports ('select_queries.sql').
5. Recorded execution screenshots in 'screenshots/'.

## Outcome
A working SQLite database ('retail_store.db'), ready to be extended with joins and extended analysis in Task 2.
